## 📌 Project Overview

This project is a **Hospital Emergency Room Dashboard** created as part of my **Data Analysis course**.  
The dashboard helps to **analyze hospital emergency data** in an easy and visual way.

Using this dashboard, we can quickly understand:
- How many patients visited the emergency room
- Average waiting time
- Patient satisfaction level
- Admission status
- Gender-wise and age-wise patient analysis
- Department-wise referrals

---

## 🎯 Objective of the Project

The main goal of this project is to:
- Convert **raw hospital data** into **useful insights**
- Help hospital management take **better decisions**
- Practice **data visualization & analysis skills**

### 👥 Key Performance Indicators (KPIs)

| Metric | Description |
|------|------------|
| **No. of Patients** | Total patients visited ER |
| **Average Wait Time** | Average time patients waited |
| **Patient Satisfaction Score** | Overall satisfaction rating |
| **Patient Attend Status** | On-time vs Delayed patients |

---

### 🚻 Gender-wise Analysis
- Male vs Female patient distribution
- Displayed using **donut chart**

---

### 🏥 Admission Status
- **Admitted vs Not Admitted**
- Percentage-based comparison

---

### 🎂 Age Group Analysis
- Patients divided into age groups:
  - 0–9, 10–19, 20–29, etc.
- Helps identify **most affected age group**

---

### 🏬 Department-wise Referral
Shows number of patients referred to:
- General Practice
- Orthopedics
- Physiotherapy
- Cardiology
- Renal
- Gastroenterology
- Neurology

---

## 📈 Key Insights (Example)

- Majority of patients are from **General Practice**
- Most patients belong to **30–49 age group**
- **Male patients** are slightly higher than females
- Around **50% patients get admitted**
- Some delays observed in patient attendance
